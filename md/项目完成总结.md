### 快速开始
```bash

.venv\Scripts\activate

# 2. 启动Web应用
python run.py web --weights runs/train/wildfire_exp4/weights/best.pt

# 3. 浏览器访问 http://127.0.0.1:5000
```

### 命令行检测
```bash
# 检测单张图像
python detect.py --weights runs/train/wildfire_exp4/weights/best.pt --source path/to/image.jpg

# 批量检测
python detect.py --weights runs/train/wildfire_exp4/weights/best.pt --source data/test/images
```
