# 云南烤烟病害检测数据集获取指南

## 🎯 目标
为云南烤烟病害检测项目收集以下5类数据：
- **健康叶片** (healthy)
- **烟草花叶病毒病** (mosaic_virus) 
- **赤星病** (brown_spot)
- **野火病** (wildfire) - 已有数据
- **青枯病** (bacterial_wilt)

## 📊 推荐数据源

### 1. PlantVillage数据集 ⭐⭐⭐⭐⭐

**获取方式：**
```bash
# 使用Kaggle API下载
kaggle datasets download -d arjuntejaswi/plant-village
```

**包含的相关类别：**
- `Tomato___healthy` → 健康叶片
- `Pepper,_bell___healthy` → 健康叶片  
- `Potato___healthy` → 健康叶片
- `Tomato___Tomato_mosaic_virus` → 花叶病毒病
- `Tomato___Bacterial_spot` → 野火病（细菌性病害）
- `Pepper,_bell___Bacterial_spot` → 野火病
- `Potato___Early_blight` → 赤星病（真菌性病害）
- `Tomato___Late_blight` → 青枯病（细菌性萎蔫）

### 2. Plant Pathology Challenge 2021 ⭐⭐⭐⭐

**获取方式：**
```bash
# Kaggle竞赛数据
kaggle competitions download -c plant-pathology-2021-fgvc8
```

**包含：**
- 18,632张高质量苹果叶片图像
- 健康和多种病害图像
- 支持多标签分类

### 3. Mendeley植物病害数据集 ⭐⭐⭐

**链接：** https://data.mendeley.com/datasets/tywbtsjrjv/1
- 61,486张图像，39个类别
- 包含多种数据增强
- CC0许可证（免费使用）

## 🛠️ 数据收集步骤

### 步骤1：设置Kaggle API
```bash
# 安装Kaggle命令行工具
pip install kaggle

# 配置API密钥 (从Kaggle账户设置中下载kaggle.json)
mkdir ~/.kaggle
cp kaggle.json ~/.kaggle/
chmod 600 ~/.kaggle/kaggle.json
```

### 步骤2：下载数据集
```bash
# 创建目录
mkdir -p data/raw/collected

# 下载PlantVillage
cd data/raw/collected
kaggle datasets download -d arjuntejaswi/plant-village
unzip plant-village.zip

# 下载Plant Pathology 2021
kaggle competitions download -c plant-pathology-2021-fgvc8
unzip plant-pathology-2021-fgvc8.zip
```

### 步骤3：处理数据集
```bash
# 运行数据处理脚本
python scripts/collect_disease_datasets.py
```

## 🔧 自动化脚本使用

### 1. 运行数据收集器
```python

# 创建收集器实例
collector = DiseaseDatasetCollector()

# 处理下载的数据
collector.process_collected_data('data/raw/collected/plant-village')

# 划分数据集
collector.split_multiclass_dataset()
```
