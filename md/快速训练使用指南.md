# 🚀 云南烤烟病害快速训练使用指南

## 📋 概述

优化后的 `train_fast_5class.py` 脚本现在具备：
- ✅ 智能GPU/CPU检测
- ✅ 动态批次大小优化
- ✅ 基于硬件的参数调整
- ✅ 详细的性能信息显示

## 🔧 主要优化

### 原始脚本问题
- ❌ 硬编码 `device: 'cpu'`
- ❌ 固定批次大小 `batch: 32`
- ❌ 未充分利用硬件资源

### 优化后特性
- ✅ **智能设备检测**: 自动选择GPU或CPU
- ✅ **动态批次优化**: 根据硬件自动调整
- ✅ **内存优化**: 根据可用内存选择缓存策略
- ✅ **混合精度**: GPU模式自动启用AMP加速

## 🎯 GPU加速设置

### 当前状态检查
您的PyTorch版本：`2.8.0+cpu` (仅支持CPU)

### 启用GPU的步骤
1. **查看详细指南**: `GPU加速安装指南.md`
2. **安装GPU版本PyTorch**:
   ```bash
   pip uninstall torch torchvision torchaudio
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
   ```
3. **验证安装**:
   ```bash
   python -c "import torch; print('CUDA可用:', torch.cuda.is_available())"
   ```

## 🔧 手动调整参数

如需手动调整，可修改脚本中的参数：

```python
# 手动指定设备
device = 'cuda'  # 或 'cpu'

# 手动指定批次大小
recommended_batch = 32

# 调整训练轮次
'epochs': 50  # 更多轮次，更好效果

# 调整数据比例
'fraction': 1.0  # 使用全部数据
```

## ❓ 常见问题

**Q: 脚本检测不到GPU？**
A: 确保安装了支持CUDA的PyTorch版本

**Q: 内存不足错误？**
A: 脚本会自动调整，如仍有问题请手动减少批次大小

**Q: 训练速度仍然很慢？**
A: 检查是否在CPU模式，参考GPU安装指南

**Q: 想要更高精度？**
A: 增加epochs到50-100，使用fraction=1.0
