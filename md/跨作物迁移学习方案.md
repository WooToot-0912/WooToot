# 云南烤烟病害检测 - 跨作物迁移学习方案

## 🎯 项目目标
利用其他植物的相似病害数据，通过迁移学习提升云南烤烟病害检测的准确性和鲁棒性。

## 📋 病害映射策略

### 1. 花叶病毒病 (Mosaic Virus)
**目标症状**: 叶片出现深浅绿相间的花叶斑驳
**相似病害数据源**:
- 番茄花叶病毒 (TMV) ⭐⭐⭐⭐⭐
- 黄瓜花叶病毒 (CMV) ⭐⭐⭐⭐
- 辣椒花叶病毒 ⭐⭐⭐⭐
- 马铃薯病毒病 ⭐⭐⭐

**相似度**: 95% (病毒感染机制相同)

### 2. 赤星病 (Brown Spot)  
**目标症状**: 叶片上圆形或椭圆形褐色病斑，有明显轮纹
**相似病害数据源**:
- 苹果疥疮病 ⭐⭐⭐⭐⭐
- 马铃薯早疫病 ⭐⭐⭐⭐
- 番茄早疫病 ⭐⭐⭐⭐
- 葡萄黑腐病 ⭐⭐⭐

**相似度**: 85% (真菌性病害，病斑形态相似)

### 3. 野火病 (Wildfire) 
**目标症状**: 不规则黄褐色病斑，周围有黄色晕圈
**相似病害数据源**:
- 番茄细菌性斑点病 ⭐⭐⭐⭐⭐
- 辣椒细菌性斑点病 ⭐⭐⭐⭐
- 桃细菌性穿孔病 ⭐⭐⭐⭐
- 豆类细菌性疫病 ⭐⭐⭐

**相似度**: 90% (细菌性病害，症状高度相似)

### 4. 青枯病 (Bacterial Wilt)
**目标症状**: 叶片失水萎蔫，不能恢复，整株枯死
**相似病害数据源**:
- 番茄青枯病 ⭐⭐⭐⭐⭐
- 马铃薯晚疫病 ⭐⭐⭐⭐
- 茄子青枯病 ⭐⭐⭐⭐
- 辣椒青枯病 ⭐⭐⭐⭐

**相似度**: 90% (细菌性萎蔫，症状几乎相同)

## 🛠️ 技术实施方案

### 阶段1: 数据收集与预处理
1. **收集相似病害数据**
   - PlantVillage数据集
   - Plant Pathology Challenge数据
   - 用户提供的其他植物病害图片

2. **数据预处理**
   - 统一图像尺寸 (640x640)
   - 色彩标准化
   - 病害特征增强

3. **标签映射**
   ```python
   disease_mapping = {
       'Tomato___Tomato_mosaic_virus': 'mosaic_virus',
       'Apple___Apple_scab': 'brown_spot', 
       'Tomato___Bacterial_spot': 'wildfire',
       'Tomato___Late_blight': 'bacterial_wilt'
   }
   ```

### 阶段2: 渐进式迁移学习
1. **预训练阶段**
   - 使用大规模植物病害数据集预训练
   - 学习通用的病害特征表示

2. **域适应阶段**  
   - 使用相似病害数据进行中间训练
   - 逐步适应烟草叶片特征

3. **微调阶段**
   - 使用野火病真实数据进行最终微调
   - 保持模型对烟草特征的敏感性

### 阶段3: 数据增强策略
1. **几何变换**
   - 旋转、翻转、缩放
   - 透视变换模拟不同拍摄角度

2. **颜色空间增强**
   - HSV变换适应不同光照条件
   - 对比度调整匹配烟草叶片色调

3. **高级增强**
   - MixUp: 混合不同作物的病害特征
   - CutMix: 组合不同病害区域
   - Mosaic: 多图像拼接增强

## ⚠️ 风险与对策

### 风险1: 域间差异过大
**对策**: 采用渐进式域适应，增加中间作物数据作为桥梁

### 风险2: 病害特征混淆
**对策**: 增强特征提取网络，使用注意力机制聚焦关键特征

### 风险3: 数据不平衡
**对策**: 使用Focal Loss，SMOTE过采样，类别权重调整
