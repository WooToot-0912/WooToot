# 景陶易购API服务器故障排除指南

## 常见问题及解决方案

### 1. 端口绑定失败

**错误信息：**
```
以一种访问权限不允许的方式做了一个访问套接字的尝试
```

**原因分析：**
- 端口被其他程序占用
- 权限不足
- 防火墙阻止

**解决方案：**

#### 方案A：更换端口（推荐）
```bash
# 运行端口检查工具
python check_ports.py

# 使用可用端口启动服务器
python simple_server.py
```

#### 方案B：以管理员身份运行
1. 右键点击 `start_server_admin.bat`
2. 选择"以管理员身份运行"

#### 方案C：手动指定端口
修改 `simple_server.py` 中的端口号：
```python
app.run(host='127.0.0.1', port=9000, debug=True)  # 使用9000端口
```

### 2. 依赖包安装失败

**错误信息：**
```
ModuleNotFoundError: No module named 'flask'
```

**解决方案：**
```bash
# 安装依赖包
pip install flask flask-cors requests

# 或者使用安装脚本
python setup.py
```

### 3. 导入TradingAPI失败

**错误信息：**
```
ModuleNotFoundError: No module named 'core.trading_api'
```

**原因分析：**
- 项目路径配置错误
- 文件结构不完整

**解决方案：**
1. 确保在 `api_server` 目录下运行
2. 检查项目结构是否完整
3. 使用绝对路径导入

### 4. 网络连接问题

**错误信息：**
```
Connection refused
```

**解决方案：**
1. 检查防火墙设置
2. 确认服务器已启动
3. 验证端口号正确

## 启动步骤

### 步骤1：检查环境
```bash
# 检查Python版本
python --version

# 检查依赖包
python -c "import flask, flask_cors, requests; print('依赖包正常')"
```

### 步骤2：检查端口
```bash
# 运行端口检查工具
python check_ports.py
```

### 步骤3：启动服务器
```bash
# 方式1：直接启动
python simple_server.py

# 方式2：使用批处理文件
start_server.bat

# 方式3：管理员模式（如果遇到权限问题）
start_server_admin.bat
```

### 步骤4：测试API
```bash
# 测试API是否正常
python test_api.py

# 或者运行客户端示例
python client_example.py
```

## 端口配置

### 默认端口
- **8080**: 原始端口（可能被占用）
- **8081**: 推荐端口（已配置）
- **8082**: 备用端口

### 自定义端口
如果需要使用其他端口，修改以下文件：

1. **simple_server.py**
```python
app.run(host='127.0.0.1', port=你的端口号, debug=True)
```

2. **client_example.py**
```python
def __init__(self, base_url: str = "http://localhost:你的端口号"):
```

3. **test_api.py**
```python
base_url = "http://localhost:你的端口号"
```

## 性能优化

### 1. 减少内存占用
```python
# 在simple_server.py中添加
import gc
gc.collect()  # 定期清理内存
```

### 2. 优化请求处理
```python
# 添加请求超时
app.config['SEND_FILE_MAX_AGE_DEFAULT'] = 0
```

## 安全建议

### 1. 生产环境
- 使用HTTPS
- 配置防火墙
- 限制访问IP
- 启用日志记录

### 2. 开发环境
- 使用本地地址（127.0.0.1）
- 避免暴露到公网
- 定期更新依赖包
