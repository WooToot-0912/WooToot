# 🎯 景陶易购智能交易系统 v2.0

基于人工智能和图像识别技术的自动交易系统，专为景陶易购平台设计。系统通过智能检测黄线角度变化（20度阈值）和K线颜色变化，自动执行交易操作并处理确认对话框。

## ⭐ 核心特性

### 🔥 主要功能
- **🎯 黄线角度检测**: 20度阈值智能角度变化检测
- **🤖 确认对话框自动处理**: 智能等待1-2秒并自动点击确认
- **🎨 K线颜色识别**: 红绿K线自动识别和交易
- **💰 实时价格填入**: 自动获取当前价格并填入
- **🛡️ 风险控制**: 内置交易间隔和信号确认机制

### 🚀 技术亮点
- **线性回归算法**: 精确计算黄线角度
- **多重检测机制**: 对话框区域、按钮、文本三重检测
- **智能等待系统**: 支持延迟出现的确认窗口
- **HSV颜色空间**: 高精度颜色识别
- **PyQt5界面**: 直观易用的图形界面

## 🚀 快速开始

### 📋 系统要求
- **操作系统**: Windows 10/11
- **Python版本**: 3.7+
- **内存**: 4GB RAM
- **显示器**: 1920x1080+

### ⚡ 一键启动
```bash
# 1. 安装依赖
pip install -r requirements/requirements_core.txt

# 2. 启动程序
python app/main_stable.py
```

### 🎯 5分钟配置
1. **连接客户端** → 点击[客户端连接]
2. **校准坐标** → 点击[坐标校准]
3. **设置阈值** → 选择"标准20°"
4. **开始监测** → 点击[🚀 开始监测]

## 📊 角度阈值说明

| 模式 | 阈值 | 特点 | 适用场景 |
|------|------|------|----------|
| 🔥 敏感 | 10° | 信号频繁 | 短线交易 |
| ⭐ 标准 | 20° | **推荐使用** | 一般交易 |
| 🛡️ 保守 | 30° | 信号稳健 | 长线交易 |

```

    ↓                                        ↓
继续监测 ←─────────────────────────────── 否
    ↓

    ↓                                    ↓
```
