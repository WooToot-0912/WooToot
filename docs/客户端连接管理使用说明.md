# 客户端连接管理功能使用说明

## 🎯 功能概述

新增的客户端连接管理功能实现了**方案1（增强窗口+界面元素检测）+ 方案2（功能性测试+自动登录）**的组合方案，为您的交易系统提供：

- ✅ **智能客户端检测** - 自动检测景陶易购客户端运行状态
- ✅ **实时连接监控** - 持续监控客户端连接状态并显示
- ✅ **自动登录管理** - 可选的自动登录功能，检测到登录界面时自动填入凭据
- ✅ **安全凭据存储** - 加密存储登录信息到配置文件
- ✅ **可视化状态显示** - 右下角状态栏实时显示连接状态

## 🚀 快速开始

### 1. 启动系统
```bash
python app/main_stable.py
```

### 2. 等待初始化
- 系统启动后会自动初始化客户端连接管理器
- 查看日志中的"✅ 客户端连接管理器初始化成功"消息

### 3. 配置连接设置
- 点击菜单栏：**工具 → 客户端连接设置**
- 在弹出的对话框中配置您的设置

## 🔧 详细配置说明

### 连接状态标签页
- **当前连接状态** - 实时显示客户端连接状态
- **客户端信息** - 显示检测到的客户端窗口信息
- **连接历史** - 记录连接状态变化日志
- **测试连接** - 手动触发连接测试

### 自动登录标签页
- **启用自动登录** - 勾选后启用自动登录功能
- **用户名/密码** - 输入您的景陶易购登录凭据
- **登录选项** - 配置最大尝试次数和超时时间

### 高级设置标签页
- **检测间隔** - 设置连接状态检测的时间间隔
- **检测方法** - 选择客户端检测算法
- **界面识别** - 配置OCR和界面元素识别参数
- **调试选项** - 开发和故障排除功能

## 📊 连接状态说明

### 状态类型及含义

| 状态 | 颜色 | 含义 | 建议操作 |
|------|------|------|----------|
| **已连接** | 🟢 绿色 | 客户端正常运行且功能可用 | 可以开始交易 |
| **需要登录** | 🟠 橙色 | 检测到登录界面 | 手动登录或启用自动登录 |
| **连接中** | 🔵 蓝色 | 正在尝试连接或登录 | 请稍等 |
| **客户端未连接** | 🔴 红色 | 未检测到客户端窗口 | 启动景陶易购客户端 |
| **连接错误** | 🔴 红色 | 检测过程中发生错误 | 查看日志或重新启动 |

### 状态栏显示位置
连接状态显示在主程序窗口的**右下角状态栏**中，格式为：`客户端: [状态文字]`

## 🔐 自动登录功能

### 启用步骤
1. 打开客户端连接设置对话框
2. 切换到"自动登录"标签页
3. 勾选"启用自动登录"
4. 输入用户名和密码
5. 点击"确定"保存

### 安全说明
- 密码使用Base64编码存储（基础加密）
- 存储在项目的配置文件中
- 仅在检测到登录界面时自动触发
- 可随时禁用或修改凭据

### 工作原理
1. 系统检测到登录界面时触发
2. 使用图像识别技术自动定位用户名输入框
3. 清空并填入保存的用户名
4. 自动定位密码输入框并填入密码
5. 找到并点击登录按钮
6. 等待登录完成并验证结果（检测是否进入交易界面）

### 技术实现
- **界面元素识别**: 使用OpenCV进行边缘检测和轮廓分析
- **智能区域搜索**: 根据UI布局规律定义搜索区域
- **自适应点击**: 自动计算最佳点击位置
- **登录验证**: 通过界面变化确认登录结果

## 🔍 故障排除

### 常见问题及解决方案

#### 1. "连接管理器未初始化"
**原因**: 系统还在初始化过程中
**解决**: 等待系统完全加载后再尝试

#### 2. "未检测到客户端"
**原因**: 景陶易购客户端未运行或窗口标题不匹配
**解决**: 
- 确保客户端已启动
- 检查窗口标题包含"景陶易购"
- 尝试不同的检测方法

#### 3. "自动登录失败"
**原因**: 登录界面识别失败或凭据错误
**解决**:
- 检查用户名密码是否正确
- 启用调试模式查看详细日志
- 手动登录后系统会自动切换到已连接状态

#### 4. "增强检测器不可用"
**原因**: 缺少依赖模块或路径问题
**解决**: 
- 检查tools目录下是否存在enhanced_client_detector.py
- 确保相关依赖已安装

## 📝 配置文件

### 存储位置
登录凭据和连接设置存储在：
```
app/config/trading_config.json
```

### 配置结构
```json
{
  "client_connection": {
    "login": {
      "auto_login_enabled": true,
      "encoded_username": "base64编码的用户名",
      "encoded_password": "base64编码的密码"
    }
  }
}
```

## 🎯 使用建议

### 推荐配置
1. **启用自动登录** - 提高便利性
2. **检测间隔设置为5秒** - 平衡性能和实时性
3. **选择"增强检测器"** - 获得最佳检测效果
4. **启用详细日志** - 便于问题诊断

### 使用流程
1. 启动交易系统
2. 配置客户端连接设置
3. 启动景陶易购客户端
4. 观察右下角连接状态
5. 等待状态变为"已连接"
6. 开始正常交易
