# K线颜色识别自动交易功能使用说明

## 🎯 功能概述

K线颜色识别自动交易功能是在现有智能交易系统基础上新增的功能，能够：

- 🔵 **识别蓝色K线** → 自动执行卖出操作
- 🔴 **识别红色K线** → 自动执行买入操作  
- 📊 **实时监控K线图** → 检测新K线的出现
- ⚡ **自动获取价格** → 实时获取最新价格并填入交易界面
- 🛡️ **风险管理** → 包含交易间隔、频率限制等保护机制

## 🚀 启用方法

### 1. 启动程序
```bash
cd 自动交易系统
python app/src/trading/main_app.py
```

### 2. 启用K线识别功能
1. 在主界面左侧控制面板中找到"⚙️ 配置设置"组
2. 勾选 **"K线颜色识别交易"** 复选框
3. 配置交易参数：
   - **交易间隔**: 设置两次交易之间的最小间隔（默认30秒）
   - **交易数量**: 设置每次交易的数量（默认1手）

### 3. 设置K线图区域
1. 点击菜单栏 **"工具"** → **"设置K线图区域..."**
2. 根据您的客户端界面调整区域参数：
   - **左边界(X)**: K线图左边的位置（0-1，默认0.02）
   - **上边界(Y)**: K线图上边的位置（0-1，默认0.15） 
   - **宽度**: K线图的宽度（0.1-1，默认0.60）
   - **高度**: K线图的高度（0.1-1，默认0.45）

> 💡 **提示**: 这些是相对坐标，0代表窗口的左边/上边，1代表右边/下边

### 4. 启动智能交易
1. 确保景陶易购客户端已打开并登录
2. 点击 **"启动智能交易"** 按钮
3. 系统将自动：
   - 连接客户端窗口
   - 启动K线监控
   - 开始颜色识别

## ⚙️ 详细配置

### K线图区域设置

根据您提供的客户端截图，紫色框区域就是K线图区域。默认参数已经针对常见布局优化：

```
左边界: 0.02 (左侧2%位置)
上边界: 0.15 (上方15%位置)  
宽度: 0.60 (占窗口宽度的60%)
高度: 0.45 (占窗口高度的45%)
```

### 交易逻辑

#### 🔵 蓝色K线检测 → 卖出
- 检测到完整的蓝色柱状图
- 自动获取当前最新价格
- 执行卖出操作

#### 🔴 红色K线检测 → 买入  
- 检测到完整的红色柱状图
- 自动获取当前最新价格
- 执行买入操作

### 安全机制

1. **交易间隔控制**: 防止频繁交易
2. **交易频率限制**: 每小时最大交易次数限制
3. **价格验证**: 确保获取到有效价格才执行交易
4. **风险管理**: 持仓限制和止损机制
5. **手动控制**: 可随时停止自动交易

## 📊 监控信息

### 运行统计
在主界面右下角可以查看：
- **运行时间**: 系统运行时长
- **K线交易**: 已执行的K线交易次数
- **成功率**: 交易成功率
- **K线信号**: 检测到的K线信号总数

### 实时日志
在"📋 运行日志"标签页中可以看到：
- K线检测状态
- 交易执行情况
- 价格获取信息
- 错误和警告信息

## 🛠️ 高级功能

### 颜色校准
如果K线颜色识别不准确，可以：
1. 点击菜单 **"工具"** → **"K线颜色校准..."**
2. 确保客户端显示K线图
3. 点击"是"进行自动校准

### 参数调整
可以根据实际情况调整：
- **检测间隔**: 降低CPU使用率或提高响应速度
- **角度阈值**: 配合黄线检测使用
- **交易数量**: 根据资金和风险控制

## ⚠️ 注意事项

1. **测试模式**: 建议先在测试环境或小额资金下验证功能
2. **网络稳定**: 确保网络连接稳定，避免交易执行失败
3. **客户端状态**: 保持客户端窗口可见且未被遮挡
4. **监控运行**: 定期检查日志，确保系统正常运行
5. **及时停止**: 如发现异常情况，立即停止自动交易

## 🔧 故障排除

### 常见问题

#### K线检测不工作
- 检查K线图区域设置是否正确
- 确认客户端窗口可见
- 尝试颜色校准

#### 价格获取失败
- 检查客户端登录状态
- 验证价格显示区域
- 重新连接客户端窗口

#### 交易执行失败
- 检查网络连接
- 确认客户端响应正常
- 验证坐标校准

### 日志分析
重要日志信息：
- `✅ K线自动交易已启动`: 功能正常启动
- `🔵 检测到蓝色K线`: 检测到卖出信号
- `🔴 检测到红色K线`: 检测到买入信号
- `❌`: 表示错误，需要注意

## 📞 技术支持

如果遇到问题：

2. 检查系统状态和客户端连接
3. 重启程序重新初始化
